# 3D Corner kiosk

In-store 1280×800 touchscreen (future retail corners). Welcome tiles → Pickup (keypad → locker), Print while you shop (queue), Recycle (live scale → credit). Files: `Kiosk.jsx`.

Open `index.html`. Composes primitives from the bundle (`window.InfillDesignSystem_d33a9b`). Imagery is placeholder (`MediaPlaceholder`).
