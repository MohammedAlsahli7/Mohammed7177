# Storefront

E-commerce site. Click-through: Home → Shop (category tabs + material filter chips) → Product (material, colour swatch, layer height, qty, add to cart) → Custom print (upload, settings, live estimate) → Cart drawer + toasts. AR toggle flips direction. Files: `Shell.jsx` (data, header, footer), `Browse.jsx`, `Detail.jsx`.

Open `index.html`. Composes primitives from the bundle (`window.InfillDesignSystem_d33a9b`). Imagery is placeholder (`MediaPlaceholder`).
